# Bildbearbeitung

- Druckgröße 300 DPI!

---- Geometrie----
Drehen: Bild, Transformation
Hilfslinien
Perspektiv Werkzeug (shift p)
Zuschneiden (shift c) -> 3:2 oder 4:5
Ebene -> Ebene auf Bildgröße

-- Varnish shimmer entfernen:
Wähle das Abwedeln/Nachbelichten-Werkzeug (Umschalt + D).
Stelle in den Werkzeugeinstellungen (unten links) den Typ auf Nachbelichten.
Setze den Bereich auf Schatten (oder Mitteltöne, wenn Schatten zu aggressiv ist).
Wähle einen großen, sehr weichen Pinsel (Härte 0).
Stelle die Exposition (Kraft) sehr niedrig ein (z. B. auf 10-15 %).

---Bearbeitung---
Farben -> Werte -> weiße Pipette auf reinweiß anwenden
Mittleren Schieber bewegen (Farbtiefe)
Heilen (H) Unreinheiten entfernen

Farben -> Sättigung (+5-+10)
PNG Export
