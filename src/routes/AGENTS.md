# src/routes/ — TanStack file-based routing

## OVERVIEW

One file per route. `__root.tsx` wraps all pages. Route tree auto-generated — never hand-edit.

## ROUTE CONVENTIONS

Every route file (except `__root.tsx`) follows this exact pattern:

- Import `createFileRoute` from `@tanstack/react-router`
- Import `motion` from `framer-motion`
- Import `PageShell` from `@/components/PageShell`
- Import `useDocumentMeta` from `@/lib/useDocumentMeta`
- Import `useTranslation` from `react-i18next`
- Export `const Route = createFileRoute("/path")({ component: PageName })`
- Component function calls `useDocumentMeta({ title: t("page.title"), description: t("page.description") })`
- Component wraps content in `<PageShell>...</PageShell>`
- i18n keys follow pattern `{page}.title` / `{page}.description`

### `__root.tsx` (special)

- Uses `createRootRoute` (not `createFileRoute`)
- Exports `<Outlet />` as root component
- Defines `notFoundComponent` — custom 404 page (no PageShell, no framer-motion, no i18n)
- No `useDocumentMeta`, no `PageShell`, no `useTranslation`

## FILE LIST

| File | Route | What it renders |
|------|-------|-----------------|
| `__root.tsx` | — | Root layout: `<Outlet />` + 404 fallback |
| `index.tsx` | `/` | Hero section + Gallery |
| `commissions.tsx` | `/commissions` | Process steps + CTA |
| `vita.tsx` | `/vita` | Artist bio + photo |
| `imprint.tsx` | `/imprint` | Address, contact, editorial info |

## NOTES

- `src/routeTree.gen.ts` is auto-generated by TanStack Router plugin on dev/build.
  Never edit manually.
- Restart dev server after adding a new route file — HMR does not pick up new
  routes.
- No SSR — pure client-side SPA.
- Component names match route purpose (Index, CommissionsPage, VitaPage,
  ImprintPage).
- Translations for route metadata live in `src/i18n/locales/{de,en,es}/`.
