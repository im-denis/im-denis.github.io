## STRUCTURE

```
├── src/
│   ├── routes/           # TanStack file-based routing
│   ├── components/       # PageShell, SiteNav, SiteFooter, Gallery
│   │   └── ui/           # shadcn/ui components (do NOT hand-edit)
│   ├── lib/              # cn() utility, useDocumentMeta hook
│   ├── hooks/            # useIsMobile()
│   ├── i18n/             # i18next config + translations (de/en/es)
│   └── assets/           # artist/ photos, paintings/ JPG files
├── .github/workflows/    # CI: deploy to Pages on main push
└── dist/                 # Build output — gitignored

```

## WHERE TO LOOK

| Task | File(s) |
|------|---------|
| **Add a route** | `src/routes/` — call `createFileRoute("/path")`, wrap in `<PageShell>` |
| **Add a painting** | `src/components/Gallery.tsx` — import image, add to `works[]` array + `rows[]` layout |
| **Change nav** | `src/components/SiteNav.tsx` — edit `links[]` array |
| **Add translations** | `src/i18n/locales/{en,de,es}/translation.json` |
| **Change colors** | `src/styles.css` — `:root` / `.dark` oklch variables + `@theme inline` block |
| **Change fonts** | `src/styles.css` — `@layer utilities` (.font-display, .font-mono-caps, .font-handwritten) |
| **Change animation** | Framer Motion — `framer-motion` import, no shared variants file |
| **Modify SEO** | `src/lib/useDocumentMeta.ts` — called in each route |
| **Deploy** | Push `main`; or `npm run deploy` for manual gh-pages |

## CONVENTIONS

- **Path alias**: `@/` → `src/` (vite-tsconfig-paths)
- **Formatting**: Prettier — 100 char width, double quotes, trailing commas all
- **Linting**: `@typescript-eslint/no-unused-vars` is OFF; react-refresh warns on non-constant exports
- **Colors**: oklch format only — no hex/rgb in theme
- **Route naming**: PascalCase component in file; `createFileRoute("/path")` export named `Route`
- **Metadata**: Every route calls `useDocumentMeta({ title, description })`
- **Animations**: PageShell has `initial/animate` fade-up; scroll animations use `whileInView` + `viewport={{ once: true }}`
- **i18n keys**: Dot-path convention (`home.title`, `paintings.river`, `nav.work`)
- **Gallery image naming**: `{id}-{slug}-{width}x{height}-{year}.jpg`
- **404 handling**: Build copies `index.html` → `404.html` for GitHub Pages SPA routing

## ANTI-PATTERNS (THIS PROJECT)

- **Do NOT hand-edit** `src/routeTree.gen.ts` — auto-generated by TanStack Router plugin
- **Do NOT hand-edit** `src/components/ui/` — these are shadcn managed components
- **Do NOT use** tailwind.config.js — Tailwind v4 config lives in `src/styles.css` via `@theme inline`
